# Mirza's Portfolio — mirzawr.com

Static site: `index.html` + `assets/`. No build step.

- **Hosting:** Vercel (auto-deploys every push to `main`).
- **Visitor counter:** `api/visits.js` (Vercel function) + Upstash Redis (Vercel → Storage).
- **Editing:** open this repo in Claude Code and describe the change; Vercel publishes it about a minute after the push.
